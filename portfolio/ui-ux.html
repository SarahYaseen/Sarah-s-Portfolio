First Alert – Fleet Safety & Incident Management Dashboard

Figma Dashboard UI Dark Theme SaaS Design System
View on Figma

I designed the UI for First Alert, a real-time fleet safety and incident management platform, in Figma. The system allows companies to report incidents, monitor alerts, manage tasks, and track safety performance through a complete dashboard experience including a 6-step reporting wizard, multi-channel alerts, and AI-based risk insights. My focus was to create a modern dark-themed interface with clear data hierarchy, strong usability, and a scalable component-based design system.
